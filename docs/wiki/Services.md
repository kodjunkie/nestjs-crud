## Description

**Nestjsx/crud** was design to support any ORM and any DB.

Here is the list of supported ORMs and those that are going to be implemented in the nearest future:

- [x] [TypeORM](https://typeorm.io) - [@nestjs-crud/typeorm](https://www.npmjs.com/package/@nestjs-crud/core) - [docs](https://github.com/kodjunkie/nestjs-crud/wiki/ServiceTypeorm)
- [ ] [Mongoose](https://mongoosejs.com/)
- [ ] [Sequelize](http://docs.sequelizejs.com/)
