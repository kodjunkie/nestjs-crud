# Cursor Pagination

> Placeholder — full content lands in Wave 3 (cursor pagination doc propagation).

`@nestjs-crud` ships opt-in cursor pagination via `@Crud({ query: { pagination: 'cursor' } })`. The default `'offset'` mode is preserved unchanged. See [Controllers](https://github.com/kodjunkie/nestjs-crud/wiki/Controllers) for offset pagination.
